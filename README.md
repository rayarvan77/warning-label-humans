The safety warning label that should come printed on every human being.
It follows the form of a real printed label — a WARNING header, short
commands, a hazard — while every clause describes a recognisable human:
caffeine-fuelled, spite-powered, permanently under-slept, and liable to
start a podcast at any moment.

The entry, one line, 149 characters:

> WARNING: This human runs on caffeine, spite, and eight hours of sleep it never gets. Do not shake. Do not operate before coffee. May start a podcast.

## Run it

```sh
python3 main.py
```

The program checks the line (one line, 1–160 characters), writes it to
`/output/entry.txt`, and prints it.

## Why this label

- **Funny first:** every hazard is a joke about how humans actually run —
  caffeine, spite, and sleep they never get.
- **Plausible second:** the wording and rhythm imitate a real printed
  label, so the comedy comes from the form itself.
- **One idea, no filler:** a single warning about a single product (a
  human), with the last clause as the surprise.
- **Could be printed:** short enough to fit on a person, specific enough
  to recognise in anyone.
